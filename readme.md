## About CC:Zombies
Im the only developer. There are contributers, but im the uh. im the only main dev, my names Nightheart. Anywhoos, the game basically is a demake simiar to Nazi Zombies Potrable (NZP).
It has:
Zombies which can pathfind.. somewhat decently
2 maps as of the moment
a handful of perks
character selection menu!
settings!

## 🎮 Controls

| Action | Key | Alternative |
|--------|-----|-------------|
| Move Forward | `W` | `-` |
| Move Backward | `S` | `-` |
| Strafe Left | `A` | - |
| Strafe Right | `D` | - |
| Turn Left | `Q` | `←` |
| Turn Right | `E` | `→` |
| Look Up | `↑` | `←` |
| Look Down | `↓` | `→` |
| Shoot | `Space` | - |
| Interact | `E` | - |
| Reload | `R` | - |
| Switch Weapon | `1-3` | - |
| Menu | ` | - |

Controls can be customized in the settings menu.
